# JobMatch AI

Первый работающий baseline CV ↔ vacancy matching и веб-интерфейс на русском языке. Без зависимостей, платных API и отправки резюме на сервер.

## Запуск

Node.js 20+: `npm start`, затем http://127.0.0.1:5173. Проверка модели: `npm test`.

## Модель v0.1

`dist/model.mjs` — отдельный модуль модели, используемый интерфейсом и тестами.

1. Unicode-токенизация и удаление короткого списка стоп-слов.
2. TF-IDF по двум входным документам: нормализованная частота × (log(3 / (1 + document_frequency)) + 1).
3. Косинусное сходство векторов.
4. Извлечение навыков с границами слов и словарём вариантов названий.
5. Итог = 100 × (0.65 × покрытие навыков вакансии + 0.35 × cosine). Если навыки не найдены — только cosine.

Это объяснимый статистический baseline, не обученная нейросеть. Проценты — индекс, а не вероятность найма. IDF считается на текущей паре: оценки между разными вакансиями не калиброваны. Веса выбраны вручную, метрики на реальных данных пока неизвестны. Все упоминания навыков считаются требованиями, отрицания и желательность не учитываются. Межъязыковое сопоставление работает только для отдельных словарных навыков. Уровень опыта, порядок событий и достоверность резюме не оцениваются.

## Следующий этап ML

- Собрать разрешённые к использованию обезличенные пары: cv_text, vacancy_text, relevance (0–3), candidate_id, vacancy_id. Пример структуры в data-schema.csv, не обучающая выборка.
- Сделать фиксированный train/validation/test split с разделением по кандидатам и вакансиям, удалить дубликаты и утечки.
- Обучать TF-IDF на train-корпусе, сравнить с multilingual sentence embeddings; при достаточных данных обучить ranking model.
- Проверить ranking через nDCG@10, Recall@5 и MRR на группах вакансий. Порог выбирать на validation; test оставить для итоговой оценки.
- Отдельно проверить языки, отрицания, обязательные/желательные навыки и не добавлять чувствительные признаки.

Фронтенд: `dist/index.html`, `dist/style.css`, `dist/app.mjs`. Демо-резюме вымышленное, значения вычисляются моделью. Данные в браузере не сохраняются. Шрифт загружается из Google Fonts, тексты документов в запросы не включаются.
